A Python program that writes one money-making plan for make.fun's "Make the AI judge rich" bounty: the plan an AI agent with $100 and 30 days would follow to end with the most money.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the plan to `out/entry.txt`.
